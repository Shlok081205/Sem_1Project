# Console Calendar & Event System

## 📅 Overview
A logic-heavy console application that generates accurate calendars and manages recurring schedules.

## 🧩 Key Features
- **Recurring Event Algorithm:** Users can set events to repeat Daily, Weekly, Monthly, or Quarterly.
- **Dynamic Calculation:** The system mathematically projects these events into future years, accounting for Leap Years and variable month lengths[cite: 15].
- **No Date Libraries:** Built entirely using loops (`for`, `while`) and control flow (`switch`) to demonstrate raw logic building.
